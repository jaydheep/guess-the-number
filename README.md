# Guess the Number

A small number guessing game. Find the secret number between 1 and 10. Numbers you rule out are crossed off the board, and your best score is saved in the browser.

Plain HTML, CSS and JavaScript, so there is no build step.

## Run locally
Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.

## Deploy
Import this repo in Vercel with the **Other** framework preset. Leave the build command empty.
